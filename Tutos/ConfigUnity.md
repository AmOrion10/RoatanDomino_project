# Configuration Unity

Explication de la configuration Unity nécessaire afin de développer le jeu.


1) Télécharger UnityHub depuis le lien [suivant](https://unity.com/download)
2) Pendant le téléchargement créer-vous un compte Unity.
3) Lancer Unity Hub et connecter-vous.
4) S'il vous proposer d'installer un éditeur faites "Skip installation"
5) Rendez-vous sur [ce lien](https://unity.com/releases/editor/archive) et choississez la version **Unity 2022.3.19** de votre OS.
6) Installer la version citée ci-dessus avec les composants suivants : 
   - Android Build Support
   - iOS Build Support
   - Linux Build Support (IL2CPP)
   - Mac Build Support (Mono)
   - WebGL Build Support
   - Windows Build Support (Mono)
7) En attendant l'installation, cliquer sur "Manage licences" sur Unity Hub puis "Add licence" et enfin "Get a free personal licence"
8) Une fois l'installation effectuée, rendez-vous sur UnityHub dans la catégorie "Projects". Cliquer sur "Add" en haut à droite et selectionner le dossier DominoGame du répertoire git. Vérifier l'utilisation de la version **Unity 2022.3.19** sur UnityHub.
9) Il ne reste plus qu'à lancer le projet !
