# Configuration Visual Studio

Explication de la configuration Visual Studio nécessaire afin de développer la partie serveur.

**Visual Studio n'est disponible que sur Windows et Mac, si vous voulez utiliser Linux dirigez-vous vers Rider de JetBrains ou configurez vscode pour utiliser du C#.**

1) Télécharger Visual Studio Community 2022 depuis [ce lien](https://visualstudio.microsoft.com/) 
2) Lancer l'installateur et sélectionner les composants suivants : 
    - ASP.Net and web development
    - .Net Multi-platform App UI development
    - .Net Desktop development
3) Laisser faire l'installateur puis une fois fini, lancer le fichier **.sln** se trouvant dans le dossier DominoServer. 

## Extensions

- **ReSharper** est recommandée car elle permet d'améliorer la qualité de code de manière générale et de bénéficier des nouvelles syntaxes du C# plus facilement.
- **NCrunch** permet de plus facilement exécuter les tests et voir le code qui est testé ou non.
